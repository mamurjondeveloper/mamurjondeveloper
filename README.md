### 👋 Men haqimda

O'zbekiston, Namangan viloyatidan bo'lgan **full-stack dasturchi**man. Kod yozishni g'oyadan haqiqiy, ishlaydigan mahsulotgacha olib borishni yaxshi ko'raman — demo emas, **production**da ishlaydigan tizimlar.

- 🚀 Hozirda **[Honumi.uz](https://honumi.uz)** — o'quv markazlari uchun to'liq EduCRM platformasini yagona dasturchi sifatida qurmoqdaman: FastAPI backend, Next.js veb-panel, ikkita React Native mobil ilova (o'quvchi va o'qituvchi uchun) va Telegram bot integratsiyasi.
- 🧠 Raqamli musobaqalar (Codeforces, algoritmik masalalar) orqali C++ va algoritmik fikrlashni chuqurlashtirib boraman.
- 🖥️ Desktop (Electron) va sun'iy intellekt asosidagi tizimlar (yuzni tanish orqali davomat) ustida ham ishlayman.
- 📚 Hozir yangi narsalarni o'rganishga va real muammolarni real yechimlar bilan hal qilishga qiziqaman.
